# 如何进一步验证 LS 方法：实验路线图

## 1. 先明确论文需要证明什么

当前 LS 分支的核心是：主膜电位照常泄漏并在放电后 reset，同时额外状态保存不被
reset 的历史；阈值判断前将历史项重新注入。因而实验不应只回答“LS 的最终准确率是否
更高”，还应分别验证以下三条因果链：

1. **机制有效**：优势确实来自 LS 历史分支，而不是参数量、训练随机性或更高放电率；
2. **长程有效**：时间间隔越长、reset 越频繁，LS 相对非 LS 的优势应越明显；
3. **代价可接受**：在相近放电率、延迟和能耗下仍有性能收益。

建议始终做成配对比较：`LIF ↔ LSLIF`、`CLIF ↔ LSCLIF`、`PLIF ↔ LSPLIF`。
如果三组都呈现相同趋势，就比只比较 LIF/LSLIF 更能说明 LS 是可迁移的通用组件。
`LSLIF4` 的“回收泄漏/reset 损失”机制应单列，不要与标准 LSLIF 混成同一方法。

## 2. 最推荐的三个实验

### 2.1 推理时 history branch knockout（优先级 P0）

**问题**：训练好的 LS 模型是否真的在使用历史分支？

#### 直观含义

这相当于对已经训练好的 LS 网络做一次“器官切除实验”。普通的 LIF/LSLIF 精度对比同时
改变了训练轨迹和最终权重，因此即使 LSLIF 更好，也无法确定优势究竟来自 history 分支，
还是来自随机初始化、正则化效应或不同的优化结果。这里固定同一个 LS 模型的所有权重和
输入，只在 forward 时干预 history 项，观察预测是否随之恶化。

对同一个 LS checkpoint、同一批测试样本，只改变推理过程：

- `normal`：保留历史项；
- `history-zero`：每步令历史项为 0；
- `history-detach`：数值不变但切断梯度（只用于训练期/梯度诊断）；
- `history-shuffle`：在 batch 内打乱历史状态，保持其边际尺度但破坏样本对应关系；
- `history-time-shift`：把历史项向后错位 1/2/4 步。

其中 `history-zero` 回答“有没有 history 会怎样”，但它可能让神经元进入训练时从未见过的
状态；`history-shuffle` 保留 history 数值的总体分布，却破坏它与当前样本的对应关系，回答
“有一个同样强的历史信号是否就够了”；`history-time-shift` 则回答“正确的时间对应关系
是否重要”。`history-detach` 不会改变推理数值，所以不应期待测试准确率变化；它只用于
重新训练或梯度诊断，区分 history 的前向信息作用与反向梯度通路作用。

#### 推荐操作步骤

1. 选择验证集确定的 checkpoint，固定测试顺序、batch 和随机噪声种子；
2. 先运行 `normal`，同时记录每层主膜项 `m_t`、history 项 `h_t`、spike 和预测；
3. 在同一批样本上分别运行 zero、shuffle 和 time-shift，干预一层、浅/中/深层以及全部层；
4. 对每个样本做配对统计，而不是只比较两个总体准确率；
5. 用一个从头训练的 `β=0` 模型作为结构消融，但不要用它替代同 checkpoint 干预。

报告 accuracy、NLL、每个样本预测变化率，以及
`Δacc = acc(normal) - acc(intervention)`。再按样本事件密度、放电次数和序列长度分组。
如果 normal 明显优于 zero/shuffle，而且差距随时间跨度或 reset 次数增加，就形成了比
“两个独立模型准确率不同”更直接的因果证据。仅做 `history-zero` 仍可能是分布外干预，
因此必须同时提供 shuffle/time-shift 控制，并画出历史项与主膜项的幅值比。

#### 它能证明什么

- normal 优于 zero：**该 checkpoint 的输出依赖 history 分支**；
- normal 同时优于 shuffle/time-shift：模型依赖的是**样本相关、时序对齐的历史信息**，
  而非 history 项单纯改变阈值或提高放电率；
- 干预越早的时间步或越深的层，影响呈现稳定规律：可以定位 LS 信息被使用的时间和层级；
- 若重新训练时 detach history 导致早期时间梯度和性能共同下降，则支持 history 也是一条
  优化通路。

它**不能单独证明** LS 比所有记忆机制更好，也不能排除“模型已经适应 LS，突然移除必然
受损”的分布外效应。因此需要下一个受控任务证明长程能力，并用从头训练的 `β=0` 配置补充。

### 2.2 可控的“线索—空白—查询”长度外推（优先级 P0）

**问题**：LS 是否真的延长了可用记忆，而不只是更适合某个固定 T？

#### 直观含义

把任务想成“先告诉网络一个秘密，等待一段时间后再提问”。例如在第 1～4 步输入红/蓝
脉冲表示类别 0/1，中间不再提供任何与标签有关的信息，最后出现完全相同的 query 脉冲，
网络只有记住开头线索才能答对。gap 越长，早期信息必须跨越的状态更新越多；因此这比
DVS 最终准确率更直接地测量时间记忆。

构造一个比 delayed XOR 更易解释的任务：前若干步给出类别线索，中间插入长度为
`D ∈ {0, 4, 8, 16, 32, 64}` 的空白或干扰，最后给统一 query，只在 query 时刻计算
分类损失。建议包含三种 gap：全零、同分布噪声、来自其他类别的干扰。

三种 gap 分别测不同能力：全零 gap 测“被动保存”；与输入统计相同但标签无关的噪声测
“抗遗忘”；其他类别干扰测“抵抗新信息覆盖”。所有模型必须使用相同输入编码、隐藏宽度、
训练样本数和优化预算，而且只在最终 query 计算 loss，避免中间监督为早期状态提供捷径。

做两种协议：

1. **同长度训练/测试**：每个 D 分别训练，画 accuracy–D 曲线；
2. **长度外推**：只在 `D≤16` 训练，在 `D=32/64` 测试，检验机制是否能泛化到未见跨度。

建议再加入两个必要对照：打乱 cue 与标签的关系后性能应回到随机水平；把 cue 直接复制到
query 前一时刻时，各模型都应恢复较高精度。这两个对照分别排除数据泄漏和任务本身不可学。

主指标除 accuracy 外，还应报告“准确率降到无 gap 性能 90%/80% 时的最大 D”，并在
相同 checkpoint 上测早期输入到最终 loss 的梯度保持率。若 LS 同时提高行为记忆跨度和
梯度跨度，机制叙事会更完整。

#### 它能证明什么

- LS 的 accuracy–D 曲线下降更慢：LS 保存可用于行为决策的信息更久；
- 只在短 gap 训练、长 gap 测试仍有优势：收益不是对固定 T 的参数拟合，而有长度泛化；
- 在噪声/冲突 gap 中优势更大：LS 不仅延缓自然衰减，也能抵抗后续输入覆盖；
- 行为 memory horizon 与时间梯度 horizon 同时增加：把“记得更久”和“梯度传得更远”连接
  成一条机制证据链。

它**不能直接证明**收益专门来自 reset 信息保存，因为长 gap 中还同时存在泄漏和梯度衰减；
这正是 reset 压力实验要进一步隔离的变量。

### 2.3 reset 压力曲线（优先级 P0）

**问题**：LS 的收益是否来自保留被 reset 丢掉的信息？

#### 直观含义

LIF 放电后会从主膜电位减去阈值或把膜电位重置。标准 LIF 的部分历史因此被抹去，而 LS
另有不 reset 的状态。如果这确实是 LS 的关键优势，那么同一任务中 reset 很少时，两者应
接近；reset 越多，标准 LIF 丢失历史的机会越多，LS 的相对收益应系统性变大。这是一个带
有明确单调趋势预测的机制实验，而不只是再做一张准确率表。

固定输入任务，系统改变 reset 频率，而不改变网络容量：

- 扫阈值或输入电流缩放，使平均每神经元放电次数覆盖低/中/高三个区间；
- 分别比较 soft reset 与 hard reset；
- 对每个样本统计真实 reset 次数，并按次数分桶比较 LS/non-LS 的正确率差。

#### 推荐的两阶段设计

**阶段 A：自然分桶（主结果）**。不修改 checkpoint 或输入，对测试集中每个样本统计各层
reset/spike 次数。以 baseline 的活动量或 LS/non-LS 的共同外生指标（例如输入事件数）分桶，
在每个桶内计算配对准确率差。不要只按 LS 自己的 spike 数分桶，否则分桶变量也受方法影响，
容易产生选择偏差。

**阶段 B：受控压力（机制补充）**。在一个合成任务或重新训练的匹配设置中扫描阈值、输入
幅值或额外脉冲，使 reset 率覆盖低/中/高区间。每个 operating point 都应重新校准或训练，
并同时报告准确率和 firing rate；直接改变已训练模型的阈值主要适合作为敏感性分析。

还可以做更强的“reset-only”干预：主膜保持完全相同，只控制 history 状态是否也在 spike
时 reset。`history-no-reset` 与 `history-reset-on-spike` 的差别比改变阈值更直接地隔离
“跨 reset 保存信息”这一因素。

关键图是横轴为 reset 次数（或 firing rate）、纵轴为 `LS − baseline` accuracy 的曲线。
预期是 reset 越频繁，LS 优势越明显；如果优势只来自更高活动量，则在相同 firing-rate
桶内通常会消失。阈值变化本身也会改变决策边界，因此论文主结果应使用“按自然产生的
reset 次数分桶”，阈值扫描作为补充实验。

#### 它能证明什么

- LS 增益随 reset 压力上升：结果符合“LS 补偿 reset 信息损失”的机制预测；
- 在匹配 firing-rate 的桶内仍有增益：优势不能仅用 LS 放电更多来解释；
- `history-reset-on-spike` 明显差于 `history-no-reset`：不 reset 的历史状态本身是关键因素；
- soft/hard reset 都有相同趋势：结论不依赖某一种 reset 实现。

它**不能只凭相关分桶就证明因果关系**：困难样本可能同时产生更多 spikes 和更低准确率。
因此应把自然分桶、受控压力和 history-reset 干预三类证据放在一起解释。

### 2.4 三个实验如何形成完整证据链

三个实验回答的是不同层次的问题，不能互相替代：

| 实验 | 核心自变量 | 最直接的结论 | 仍需排除的替代解释 |
| --- | --- | --- | --- |
| history knockout | 同模型中 history 是否正确存在 | 模型是否实际使用 LS 信息 | 突然移除造成分布外状态 |
| cue-gap-query | cue 到 query 的距离/干扰 | LS 是否延长可用记忆 | 泄漏、reset、优化效应混在一起 |
| reset 压力 | reset 次数及 history 是否随之 reset | 优势是否与跨 reset 保存有关 | 样本难度与 spike 数的相关性 |

最理想的结果是：LS 在长 gap 上更好；对该模型打乱/清零 history 后优势消失；并且这种
下降主要发生在 reset 多的样本或 `history-reset-on-spike` 条件下。三者同时成立时，可以
较有力地表述为：**LS 的不重置历史分支保留了跨时间、跨 reset 的任务相关信息，从而提高
长程决策能力**。仍应避免写成数学意义上的“完全证明”，而应称为相互支持的行为、干预和
机制证据。

### 2.5 需要重跑旧网络，还是重新设计网络和数据？

结论是：**三种情况都有，但不应把所有实验都重新设计，也不应只复用旧 checkpoint**。
三个实验分别承担“现有模型诊断”“受控机制验证”和“现有任务上的机制关联”，最合理的
资源分配如下：

| 实验 | 网络结构 | 数据 | 是否重新训练 | 推荐用途 |
| --- | --- | --- | --- | --- |
| history knockout 主实验 | 完全复用旧网络 | 完全复用原测试集 | 否，直接加载旧 checkpoint | 证明现有 LS 模型确实使用 history |
| `β=0` / detach 补充消融 | 复用旧 backbone，只改 LS 开关 | 复用原训练/测试集 | 是，LS 与基线都按相同 seed 重训 | 排除突然移除分支的分布外效应 |
| cue-gap-query | 建议使用新的小型、容量匹配网络 | 新的可控合成序列 | 是，从头训练所有方法 | 纯粹测量长程记忆和长度外推 |
| reset 自然分桶 | 完全复用旧网络 | 完全复用原测试集 | 否 | 检查真实任务中 LS 增益与 reset 的关系 |
| reset 受控压力 | 复用同一种小网络或原 backbone | 合成数据优先；原数据作补充 | 严格结果应重训/校准 | 隔离 reset 压力，验证单调机制预测 |
| history-reset 干预 | 复用旧网络并改 forward 开关 | 复用原测试集 | 先不重训；再补充配对重训 | 直接测试“不 reset 的 history”是否关键 |

#### 对当前仓库最省算力的执行方案

1. **第一轮完全不重训**：使用已有 DVS-CIFAR10、`T=16` 的 LIF/LSLIF checkpoint，先做
   normal/zero/shuffle/time-shift、reset 自然分桶和 history-reset 推理干预。这一轮回答
   “当前已经训练出的网络有没有使用 LS，以及使用程度是否与 reset 有关”。
2. **第二轮只训练小模型**：基于现有 delayed-XOR 实验代码扩展 cue-gap-query 数据生成器，
   固定一个小型 FC/SNN backbone，只替换 LIF/LSLIF，扫描 gap。这里没有必要使用 VGG11，
   因为目标是隔离时间记忆，过大的网络反而可能通过容量掩盖神经元差异。
3. **第三轮再重训主网络**：只有前两轮出现预期趋势后，再在原 DVS backbone 上用至少 5 个
   配对 seed 重训 `LIF`、`LSLIF`、`LSLIF(β=0)`，并补做 `T=8/16/32`。这一轮用于确认
   小型机制实验的结论可以迁移回真实任务。

#### 为什么要这样拆分

- 只用旧 checkpoint：成本低且能说明现有模型如何工作，但干预可能产生训练分布外状态；
- 全部重新设计：机制最容易控制，但可能被质疑只在“玩具任务”有效；
- 旧真实任务 + 新合成任务 + 主网络配对重训：三者结合，既有现实性，又有因果可解释性。

因此，如果当前只想快速判断方向，**不需要马上把所有网络重跑一遍**；先完成第一轮即可。
如果目标是形成论文级证据，则最终仍需要第二轮的受控任务和第三轮的多 seed 配对重训。

## 3. 第二梯队实验

### 3.1 时间截断与因果定位

在完整序列的同一个 checkpoint 上测试 prefix-only、suffix-only、随机删除连续 block，
并扫描截断位置 `k`。除准确率外，计算完整预测与截断预测的 Jensen–Shannon divergence。
仓库已有 prefix mask、early-cue/late-noise 和 suffix spike similarity 工具，下一步应把
它们组织为统一的 `k` 曲线，而不是只展示少数配置。预注册的主要对比应是“长遮挡区间
上的曲线面积 AUC”，避免事后挑选 LS 最占优的 k。

### 3.2 信息可解码性 probe

冻结训练好的网络，在浅/中/深层每个时间步的膜状态或 spike count 上训练同容量线性
probe，预测早期 cue 的类别。画 probe accuracy 随 cue 后时间距离的衰减曲线。这个实验
直接回答“信息是否仍存在”，与最终分类器是否学会读取该信息相互独立。probe 的训练集
必须与主模型训练集分开，LS/non-LS 使用相同正则与相同样本。

### 3.3 LS 分支位置消融

保持 backbone 不变，只在 shallow、middle、deep、all layers 开启 LS，并同时报告参数量、
状态内存和性能。若只在少数层启用就能保留大部分收益，可形成更实用的结论；如果深层
更有效，也能解释历史信息在语义层级中的作用。不要把不同层数的结果直接称为“公平能耗
对比”，应另提供匹配状态内存预算的配置。

### 3.4 鲁棒性与时间形变

事件数据可测试 event drop、时间抖动、速度缩放、帧重复和时间反转。时间反转是负控制：
若任务本身依赖因果顺序，所有方法都应明显退化；若 LS 在所有破坏下都不降，反而可能说明
模型没有利用时间。推荐画 corruption severity–accuracy 曲线和相对干净数据的下降幅度，
而不是只报单一噪声强度。

### 3.5 精度—放电—延迟 Pareto 前沿

除现有平均 firing rate 外，增加每层 spike 数、零放电比例、峰值状态内存、单样本延迟和
估算能耗。通过阈值或稀疏正则为每个方法产生多个 operating points，比较 Pareto front。
LS 推理会多维护一个状态，不能只用 spike 数宣称总体能耗更低；应把主膜/历史状态更新的
额外算术与内存访问明确列入估算，并同时给出真实硬件延迟。

## 4. 必做消融矩阵

| 因素 | 建议取值 | 要回答的问题 |
| --- | --- | --- |
| history weight `β` | `0, 0.25, 0.5, 1.0, learned` | `β=0` 是否退化为基线，收益是否稳定 |
| normalization power `p` | `0, 0.5, 1.0, learned` | 长序列后历史项是否被过度缩小 |
| history mode | `all, post_spike, half` | 历史注入何时/何层最有效 |
| 时间长度 T | `4, 8, 16, 32` | 相对收益是否随时间跨度增加 |
| reset | soft / hard | LS 是否对 reset 形式稳健 |
| surrogate | 至少 2 种 | 结论是否依赖某个替代梯度 |

`β=0` 是最重要的结构消融，但要区分两种用法：从头以 `β=0` 训练用于容量匹配；对已训练
模型在推理时设 `β=0` 用于 branch knockout。两者回答不同问题，不能互相替代。

## 5. 公平性与统计规范

- 至少 5 个固定 seed；每个 seed 的 LS 与 baseline 共用数据划分、初始化的非神经元权重、
  batch 顺序和增广随机流；
- 主结果报告 seed 配对差值的均值、95% bootstrap CI 和配对检验，同时给每个 seed 散点；
- 超参数预算一致：不能只精调 LS；若分别调参，两个方法使用相同搜索空间和 trial 数；
- 同时报告 best-validation checkpoint 与最后若干 epoch 平均，测试集不能用于选 checkpoint；
- 检查参数量、训练 FLOPs、状态内存、峰值显存、训练时间和推理时间；
- 准确率之外至少报告 NLL/ECE、firing rate、时间梯度保持和扰动后的性能下降；
- 所有曲线先规定汇总量（例如 AUC、90% memory horizon），避免只挑有利时间点。

## 6. 建议的最小执行顺序

有限算力下可按下列顺序推进：

1. **无需重训**：对现有 5-seed checkpoint 做 normal/zero/shuffle history knockout，复用
   现有 early-cue、prefix-mask、梯度和 firing-rate 分析；
2. **小规模机制任务**：做 cue-gap-query 的 gap 长度外推与 reset 压力曲线；
3. **主数据集确认**：在 DVS-CIFAR10 的 `T=8/16/32` 上比较三组配对方法，并完成
   `β/p/history_mode` 消融；
4. **论文完整性**：补充跨数据集结果、5-seed 统计和精度—能耗 Pareto 图。

最有说服力的最小图组是：**(a)** accuracy–gap length，**(b)** LS 增益–reset 次数，
**(c)** history intervention 的性能下降，**(d)** 时间梯度保持率，**(e)** accuracy–energy
Pareto front。这五张图分别覆盖行为、机制、因果干预、优化和代价，能避免仅靠最终准确率
支撑结论。
