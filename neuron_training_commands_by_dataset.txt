# 训练命令清单（按数据集划分，含神经元特有参数）
# 说明：
# 1) 每个数据集都按 CIFAR-10 的详细格式展开：每个神经元单独给出说明与可复制命令。
# 2) 每条命令都显式写出该神经元“特有参数”，且初始值与 train.py 默认值一致。
# 3) 可直接复制运行；后续调参只改对应参数即可。
# 4) 如需启用 ASN，可在任意 4D 卷积神经元实验命令后追加：
#      -asn_enable -asn_p 0.5 -asn_rho 0.5 -asn_seed 2022
#    如需阻断侧抑制场梯度，再追加：-asn_detach_lateral
# 5) HALIF 专属参数说明（方便调参）：
#    -halif_auto_ratio 0.1：每层按 [C,H,W] 或 [C] 位置随机选为 autonomous neurons 的比例。
#    -halif_num_auto_groups 3：将 autonomous neurons 平均分配到多少个固定内在驱动强度组。
#    -halif_drive_periods：若不显式给 -halif_auto_drive_values，则按 v_threshold / period 计算各组驱动；默认由当前 T 形成 [2T, T, max(1,T//2)]。
#    -halif_auto_drive_values：显式指定各组 intrinsic drive，优先级高于 -halif_drive_periods。
#    -halif_v_reset 0.0：autonomous neurons 发放后的 hard reset 电位。
#    -halif_auto_seed 2022：固定 auto_mask 随机选择，便于复现实验。
# 6) QKVLIF 专属参数说明（方便调参）：
#    -qkv_alpha 0.1：注意力上下文注入膜电位的系数，膜电位更新为 total_mem = lif_mem + qkv_alpha * context；越大历史输入影响越强。
#    -qkv_learn_alpha True：是否让 qkv_alpha 作为可学习参数；True 时训练会自动调整历史注意力强度，False 时固定使用命令行给定值。
#    -qkv_max_history 0：每个神经元缓存多少个历史时间步；0 表示保留当前样本序列内全部历史，正整数表示只保留最近 K 步以省显存/计算。
#    -qkv_detach_history False：是否对缓存的历史膜电位和输入 detach；True 会省梯度图显存但切断跨历史步的 attention 梯度。
#    -qkv_w_q/-qkv_w_k/-qkv_w_v 1.0：Q/K/V 的标量投影初值；-qkv_learn_w True 时会随模型参数一起训练。

# LIF（vanilla，无额外特有参数）
python train.py -data_dir ./data_dir -dataset cifar10 -model spiking_resnet18 -T_max 200 -epochs 200 -weight_decay 5e-5 -neuron_model LIF
# SRLIF（Synaptic Release LIF；普通 spike 后增加确定性可学习释放阈值，reset 仍由原始 spike 触发）
python train.py -data_dir ./data_dir -dataset cifar10 -model spiking_resnet18 -T_max 200 -epochs 200 -weight_decay 5e-5 -neuron_model SRLIF \
  -release_threshold_init 0.0 -v_threshold 0.8 -srlif_release_ratio 0.5
# SRLIF2（突触释放与胞体 spike 解耦；释放只由 reset 前膜电位和可学习释放阈值决定）
python train.py -data_dir ./data_dir -dataset cifar10 -model spiking_resnet18 -T_max 200 -epochs 200 -weight_decay 5e-5 -neuron_model SRLIF2 \
  -release_threshold_init 0.6 -v_threshold 0.8
# SCRLIF（特有参数：spike-cause reset；q/r 仅在放电位置计算）
python train.py -data_dir ./data_dir -dataset cifar10 -T_max 200 -epochs 200 -weight_decay 5e-5 -model spiking_resnet18 -neuron_model SCRLIF \
  -scr_r0 0.8 -scr_alpha_in 0.2 -scr_alpha_exc 0.1 -scr_alpha_isi 0.1 -scr_r_min 0.7 -scr_r_max 1.2 -scr_tau_isi 4 -scr_init_isi 4

# SCRLIFV2（特有参数：正贡献比例互补 reset；只在 spike 时触发，默认不 detach reset）
python train.py -data_dir ./data_dir -dataset cifar10 -T_max 200 -epochs 200 -weight_decay 5e-5 -model spiking_resnet18 -neuron_model SCRLIFV2 \
  -tau_eps 1e-6

# HALIF（异质自主 LIF；10% autonomous neurons，3 个固定驱动组，默认按当前 T 形成 [2T, T, T/2] 自发周期）
